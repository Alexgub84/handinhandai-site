# HIHA Web — UI Kit

A modular, click-thru recreation of the **Hand in Hand Agents** marketing website. Built from the figma source-of-truth (frames `HIHA-Web`, `HIHA-Web2`, `HIHA-Web3`, `HIHA-Web4`).

## Files

- `index.html` — the demo. Routes between Home, About ("Meet Alex"), Services, and a CTA-only page using a tiny client-side router.
- `Header.jsx` — sticky frosted-glass nav with logo, links, language pill.
- `Hero.jsx` — eyebrow + 2-line H1 + sub + CTA pair, sitting on the shade-blob.
- `PainPointGrid.jsx` — staggered rows of pill capsules.
- `SolutionPill.jsx` — gradient pill section opener.
- `ProcessStep.jsx` — numbered green-tinted step card.
- `ToolChip.jsx` — floating "Automate CRM" chip.
- `Testimonial.jsx` — 5-star card with quote + name.
- `UserPainCard.jsx` — orange-bordered "USER PAIN" service card.
- `CTABlock.jsx` — bottom-of-page "Talk to Us" pair.
- `Footer.jsx` — black footer plate.
- `Buttons.jsx` — primary / secondary / language buttons.
- `ShadeBlob.jsx` — the diffuse atmospheric circle.

## Design canvas

1440px wide. 1064px content band, centered (188px gutters). All token references resolve to `../../colors_and_type.css`.
